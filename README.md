# Tooly AI – Landing Page & Documentation

Static marketing site and setup documentation for **Tooly AI**, a Flutter AI chatbot app (21+ AI tools, Gemini/Groq/OpenAI, Firebase, AdMob, in-app purchases).

- `index.html` – landing page with interactive screenshot showcase
- `docs.html` – developer documentation
- `shots/` – optimized app screenshots

No build step. Deploy the repo root as a static site (e.g. Vercel).
