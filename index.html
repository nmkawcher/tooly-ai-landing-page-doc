Frequently Asked Questions

Everything you need to know about setting up and publishing Tooly AI.

What are coins and how do they work in Tooly AI? +
Coins are virtual credits used to pay for AI computational requests (e.g., Chat costs 2 coins, Code generation costs 5 coins). Users start with free welcome coins, earn coins by watching rewarded AdMob ads or referring friends, or buy coin packs via In-App Purchases.
How does the Multi-Provider AI Fallback Engine work? +
The app uses `ApiKeyManager` and `UnifiedAIService` to manage multiple AI providers. Google Gemini is the primary engine. If Gemini encounters rate limits or quota limits, the app automatically switches requests to Groq, Cohere, Hugging Face, or OpenAI without breaking the user experience.
Can end users configure their own API keys inside the app? +
Yes! Users can navigate to Settings → API Settings in the app and input their own OpenAI, Gemini, or Groq API keys. Keys entered on-device are saved securely in local storage and take priority over default app keys.
Which Flutter version is supported? +
The project supports Flutter 3.10+ up to the latest stable Flutter 3.27+ releases (Dart SDK `>=3.0.0 <4.0.0`).
What is included with the source code purchase? +
You receive full Flutter source code for iOS and Android, all asset source files, configuration files, and complete documentation (this documentation site) covering app renaming, Firebase setup, AdMob, and store submission.
